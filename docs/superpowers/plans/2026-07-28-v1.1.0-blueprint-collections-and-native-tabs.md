**Goal:** Implement shapez native pill tabs for tag filtering, add flexible grid sorting controls (A-Z, Date, Entity Count), and introduce Factorio-style Blueprint Collections (Books) with bulk export/import.

- **Collections View**: Added basic check in `renderGrid()` to handle `this.activeTab === 'books'` state.

## Global Constraints
- **Singleton `BlueprintStore`**: Access through `BlueprintStore` object literal and read/write settings via `this.mod.settings.collections`.
- **Actual Store Blueprint Schema**: Blueprint entries are shaped `{ id, name, value, tags, createdAt }`. Use `createdAt` (not `date`).
- **Cache-Backed Sorting**: Entity count and cost sorts must read from `_cardCache` or computed helpers (`getBlueprintCost`/`getBlueprintEntityCount`), not assume properties directly on raw store entries.
- **Dynamic Click Cleanup**: Use `this.trackDynamicClick(element, handler)` (not `this.dialog.trackClicks`) for elements re-rendered inside dynamic tab containers.
- **Scoped CSS for Dynamic Tabs**: Add `.bplib-tab` and `.bplib-tab.active` CSS in `src/styles.js` so dynamically generated tag buttons highlight correctly.

Add to `BlueprintStore`:
```javascript
getCollections() {
    return (this.mod && this.mod.settings && Array.isArray(this.mod.settings.collections))
        ? this.mod.settings.collections
        : [];
},
saveCollection({ id, name, description = "", tags = [], blueprintIds = [] }) {
    const collections = this.getCollections();
    const existingIdx = collections.findIndex(c => c.id === id);
    const item = {
        id: id || `col_${Date.now()}_${Math.random().toString(36).substr(2, 5)}`,
        name: (typeof name === "string" && name.trim()) ? name.trim() : 'Untitled Collection',
        description, tags: Array.isArray(tags) ? tags : [], blueprintIds: Array.isArray(blueprintIds) ? blueprintIds : [],
        updatedAt: Date.now()
    };
    if (existingIdx >= 0) collections[existingIdx] = item;
    else collections.push(item);
    this.mod.settings.collections = collections;
    this.persist();
    return item;
},
removeCollection(id) {
    if (!this.mod || !this.mod.settings) return;
    this.mod.settings.collections = this.getCollections().filter(c => c.id !== id);
    this.persist();
},
exportCollectionAsJson(colId) {
    const col = this.getCollections().find(c => c.id === colId);
    if (!col) return null;
    const allBps = this.getAll();
    const bpsInCol = allBps.filter(bp => col.blueprintIds.includes(bp.id));
    return JSON.stringify({
        version: "1.1.0", type: "BlueprintBookCollection",
        collectionName: col.name, description: col.description, blueprints: bpsInCol
    }, null, 2);
}
```
*(Also ensure that `BlueprintStore.remove(id)` scrubs deleted IDs from existing collections to prevent dangling references, by mapping over `this.getCollections()` and filtering `blueprintIds`)*
