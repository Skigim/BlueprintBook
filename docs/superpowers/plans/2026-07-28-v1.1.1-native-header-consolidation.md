# BlueprintBook v1.1.1 – Native Header Consolidation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consolidate the Blueprint Book dialog header into a single native Shapez-style `.filterHeader` grid row — pill tabs on the left, controls on the right — exactly matching the user mockup and the native `HUDStatistics` DOM pattern.

**Architecture:** Mirror the `HUDStatistics` DOM structure (`filterHeader > filtersDataSource` + `filterHeader > filtersControlCluster`) but provide our own scoped CSS in `src/styles.js` since native `statistics.scss` rules are scoped to `#ingame_HUD_Statistics` and do not apply to our dialog. The existing `.bplib-toolbar` div and its CSS will be removed. `renderNativeTabs()` will be updated to target `.filtersDataSource` inside the header. A new `.filtersControlCluster` flex row replaces the old toolbar. No card logic changes.

**Tech Stack:** JavaScript (ESM), esbuild bundle, Vitest tests, existing `shapez` global.

## Global Constraints

- `BlueprintStore` is a plain object literal singleton — never `new BlueprintStore()`.
- All dynamic click listeners MUST use `this.trackDynamicClick(element, handler)` — never `addEventListener` directly on re-rendered elements.
- `persist()` is synchronous try/catch, no Promise queue.
- No scope creep: do NOT touch blueprint card rendering, store logic, or sort logic.
- 100% Vitest test pass required (`npx vitest run`) before commit.
- Commit after each task.

**Why NOT native engine CSS?** `statistics.scss` scopes `.filterHeader { display: grid; grid-template-columns: auto 1fr }` inside `#ingame_HUD_Statistics`. Our dialog renders inside `.dialogMods`, not inside that ID, so native grid CSS will NOT apply. We recreate the layout ourselves in `src/styles.js` using identical structure but our own selector.

### Step 1.3: Update `renderNativeTabs()` to target `#bplib-tabs`

Replace the container lookup logic (currently looks for `.filterHeader` then clears it). Now target `.filtersDataSource` / `#bplib-tabs`:

```javascript
renderNativeTabs(container) {
    if (!container) return;
    const tabsContainer = container.querySelector('#bplib-tabs')
        || container.querySelector('.filtersDataSource');
    if (!tabsContainer) return;

    tabsContainer.innerHTML = '';
    const items = this.filtersDataSource;
    items.forEach(item => {
        const btn = document.createElement('button');
        btn.className = 'bplib-tab';

        let isActive = false;
        if (item.id === "all") {
            isActive = (this.activeTab === "all" || (!this.activeTab && !this.activeTagFilter));
        } else if (item.id === "books") {
            isActive = (this.activeTab === "books");
        } else {
            isActive = (this.activeTagFilter === item.id || this.activeTab === item.id);
        }
        if (isActive) btn.classList.add('active');
        btn.textContent = item.label;

        this.trackDynamicClick(btn, () => {
            if (item.id === "all") {
                this.activeTab = "all";
                this.activeTagFilter = null;
            } else if (item.id === "books") {
                this.activeTab = "books";
                this.activeTagFilter = null;
            } else {
                this.activeTab = item.id;
                this.activeTagFilter = item.id;
            }
            this.render();
        });
        tabsContainer.appendChild(btn);
    });
}
```

### Step 1.4: Update `render()` to wire sort direction and view mode buttons

Replace the current `render()` body with:

```javascript
render() {
    try {
        this.cleanupDynamicClickDetectors();

        // Tabs
        if (this.overlay) {
            this.renderNativeTabs(this.overlay.querySelector('.bplib-dialog-content') || this.overlay);
        }

        // Sort direction toggle
        const sortDirBtn = this.overlay.querySelector('#bplib-sort-dir');
        if (sortDirBtn) {
            sortDirBtn.textContent = this.sortDescending ? '↓' : '↑';
            this.trackDynamicClick(sortDirBtn, () => {
                this.sortDescending = !this.sortDescending;
                this.renderGrid();
            });
        }

        // View mode buttons + data-displaymode attribute for CSS active state
        const header = this.overlay.querySelector('.bplib-header');
        if (header) header.setAttribute('data-displaymode', this.currentViewMode);

        const listBtn = this.overlay.querySelector('#bplib-view-list');
        const gridBtn = this.overlay.querySelector('#bplib-view-grid');
        if (listBtn) {
            this.trackDynamicClick(listBtn, () => {
                this.currentViewMode = 'detailed';
                if (header) header.setAttribute('data-displaymode', 'detailed');
                this.renderGrid();
            });
        }
        if (gridBtn) {
            this.trackDynamicClick(gridBtn, () => {
                this.currentViewMode = 'icons';
                if (header) header.setAttribute('data-displaymode', 'icons');
                this.renderGrid();
            });
        }

        // Update availability button (unchanged)
        const updateBtn = this.overlay.querySelector('#bplib-btn-update');
        if (updateBtn) {
            this.trackDynamicClick(updateBtn, () => { this.toggleUpdateDialog(); });
        }

        this.renderGrid();
    } catch (err) {
        console.error("Error in render():", err);
        this.notify("Error rendering Blueprint Book. Check console.", NOTIFY.error);
    }
}
```
